01 / THE IDEA

A small hello.
A little more connection.

Start on the badge. Bring a phone into the conversation. Carry it forward with an NFC card. The OS brings Hello, personal projects, and a photo constellation together on one touchscreen.

The browser preview simulates phone, Wi-Fi, and card events. It doesn’t create live introductions or write NFC tags.

02 / GET IT RUNNING

From source
to small screen.

Flash the badge’s onboard memory over USB. You’ll build the firmware for the Waveshare ESP32-S3-Touch-LCD-5B, then upload it directly to the board.

Before you start

  • Waveshare ESP32-S3-Touch-LCD-5B and a USB data cable
  • A Mac with Git, Python 3.12 or 3.13, CMake, Ninja, and dfu-util
  • The project source and an internet connection for setup

This first-pass guide follows the project’s macOS scripts. See Espressif’s ESP-IDF guide ↗ for other platforms.

  1. 01

    Prepare the tools

    Firmware source downloads will be added in a later pass. If you already have the PET firmware project, open that folder and install the build tools. If Homebrew isn’t installed, follow the official macOS prerequisites first.

    brew install cmake ninja dfu-util python@3.13
./scripts/setup.sh

    Setup installs ESP-IDF v5.4.2 and the ESP32-S3 toolchain. For Python 3.12, run PET_PYTHON=python3.12 ./scripts/setup.sh.

  2. 02

    Build the firmware

    Run this from the project folder. Wait for the build to finish successfully before flashing.

    ./scripts/build.sh

    The build script stages files in /private/tmp/pet-v4-build, keeping the ESP-IDF build path free of spaces.

  3. 03

    Connect & flash

    Connect the board’s USB programming port with a data cable. Close any serial monitor, then run the flash script. Keep the cable connected until flashing and verification finish.

    ./scripts/flash.sh

    This replaces the firmware currently on the board. No SD-card image or disk formatter is needed.

  4. 04

    Meet your [pet.]

    Open the serial monitor to check startup, then look for the home screen on the badge. Exit the monitor with Ctrl + ].

    ./scripts/monitor.sh

    Connect through Settings → Wi-Fi on the badge. Live Hello also needs a hosted service and a provisioned device key; flashing alone doesn’t configure those. Service provisioning notes will be added with the source release. NFC needs the compatible reader and supported tags.

Board not showing up?

Try a known data cable and the board’s programming USB port. The scripts auto-select only when exactly one USB serial device is present. List the ports, then use your board’s actual path for both commands:

python3 scripts/port.py
PET_PORT=/dev/cu.usbmodem101 ./scripts/flash.sh
PET_PORT=/dev/cu.usbmodem101 ./scripts/monitor.sh

/dev/cu.usbmodem101 is an example. If you can’t connect, hold BOOT, press and release RESET, then release BOOT and retry. For ongoing connection problems, consult Espressif’s troubleshooting guide.

Setup worked before, but ESP-IDF is missing?

The scripts keep their SDK, tools, and build under /private/tmp. macOS can clear temporary files. Run setup and build again, or set PET_IDF_PATH, PET_IDF_TOOLS_PATH, and PET_BUILD_ROOT to persistent paths without spaces before running all scripts.
